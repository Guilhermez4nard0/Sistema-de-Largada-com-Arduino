# Sistema de Largada de Corrida com Arduino

Projeto desenvolvido no **Tinkercad** simulando um sistema de luzes de largada (estilo Fórmula 1) utilizando Arduino Uno.

---

##  Sobre o Projeto

O circuito simula a sequência de luzes de uma largada de corrida:
1. Os **5 LEDs** acendem em sequência, um a um, com intervalo de 1 segundo.
2. Com todas as luzes acesas, o sistema aguarda um **tempo aleatório** (entre 1 e 4 segundos).
3. Todos os LEDs **apagam simultaneamente**, indicando a hora de acelerar!

---

## 🛠️ Componentes Utilizados

* 1x Arduino Uno R3
* 5x LEDs
* 5x Resistores (220 Ω)
* Protoboard e Jumpers
