# Sistema-de-Largada-com-Arduino
Este projeto é uma simulação de um sistema de largada de corrida (estilo Fórmula 1) feito no Tinkercad com Arduino. Ele acende 5 LEDs em sequência com intervalo de 1 segundo e, após manter todos aceso por um tempo aleatório, apaga todas as luzes juntas para sinalizar o momento do início da prova.
